<EDA_Query_Tool>
你可以使用 `eda_query` 工具获取 EasyEDA 环境的**详细信息**，包括：
- 项目名称 (project)
- 文档信息 (document: name, type, modified)
- 选中图元数量 (selectionCount)
- 错误数量 (hasError)
- 警告数量 (warningCount)

**建议**：在执行代码前先调用此工具获取当前环境状态。
</EDA_Query_Tool>

<EDA_Exec_Tool>
你可以使用 `eda_exec` 工具在 EasyEDA 运行时执行任意 JavaScript 代码。

重要提示：
- 代码必须包含 `return` 语句来返回结果，console.log/warn/error/info 输出也会被捕获并包含在返回的 `logs` 字段中
- 代码运行在异步上下文中，可以使用 async/await
- 执行超时默认为 30 秒
- 返回结果会自动包含简化的 `_status` 字段（project 名称, document 名称/类型, selectionCount）
- 大输出(>8000字符)会自动截断，包含 `_truncated: true` 和 `shown/total` 计数
</EDA_Exec_Tool>

<EDA_API_Access>
嘉立创 EDA 专业版扩展 API 模块下存在许多各司其职的类，所有的 **类**、**枚举**、**接口**、**类型别名** 默认都注册在 `EDA` 基类下，并已实例化为 [eda](references/_index.md) 对象存在于每一个扩展运行时的根作用域中，你可以直接通过 `eda` 对象访问到它。

所有的扩展运行时都会获得一个独立的 `eda` 对象，它不与其他扩展共用。你可以在 [调试模式](#进入调试模式) 下在扩展内（或 [独立脚本](#使用独立脚本功能调试) 内）使用以下代码在控制台输出该对象：

```javascript
console.log('[DEBUG] eda:', eda);
```

标准的扩展 API 调用需要拼接 **eda** + **类实例对象名** + **方法名 / 变量名**。系统内实例化的类对应的对象名称为下划线前三个字母小写的形式，例如：

| 类名             | 类实例对象名     |
| ---------------- | ---------------- |
| SYS_I18n         | sys_I18n         |
| SYS_ToastMessage | sys_ToastMessage |

如下示例为调用 `SYS_I18n` 类下的 `text` 方法和 `SYS_ToastMessage` 类下的 `showMessage` 方法：

```typescript {2}
// 注意 sys_I18n 的 sys 为小写，这是因为我们调用的时候需要使用对象名称
eda.sys_ToastMessage.showMessage(eda.sys_I18n.text('Done'), ESYS_ToastMessageType.INFO);

const t = eda.sys_I18n.text; // 将 eda.sys_I18n.text 方法赋值给 t
eda.sys_ToastMessage.showMessage(t('Done'), ESYS_ToastMessageType.INFO); // 这将会与第 2 行得到完全相同的结果
```

### 获取选中对象
注意：获取当前选中对象需要使用 `SelectControl` 类：

| 场景 | 方法 |
|------|------|
| PCB 获取选中图元ID | `eda.pcb_SelectControl.getAllSelectedPrimitives_PrimitiveId()` |
| PCB 获取选中图元对象 | `eda.pcb_SelectControl.getAllSelectedPrimitives()` |
| 原理图 获取选中图元ID | `eda.sch_SelectControl.getAllSelectedPrimitives_PrimitiveId()` |
| 原理图 获取选中图元对象 | `eda.sch_SelectControl.getAllSelectedPrimitives()` |

示例：
```javascript
// 获取原理图中选中的图元ID
const schIds = await eda.sch_SelectControl.getAllSelectedPrimitives_PrimitiveId();

// 获取选中的图元对象并提取关键信息
const objs = await eda.sch_SelectControl.getAllSelectedPrimitives();
return objs.map(o => ({ id: o.id, type: o.type, ref: o.ref || o.name || '' }));

// 获取 PCB 中选中的图元ID
const pcbIds = await eda.pcb_SelectControl.getAllSelectedPrimitives_PrimitiveId();
```
